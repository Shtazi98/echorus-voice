# Пост в Telegram

**Вариант короткий (для канала):**

Голосовой ввод на русском для DeepSeek Harness 🎙

Штатная кнопка микрофона понимает китайский, английский, японский, корейский и кантонский. Русского в этом списке нет — на русскую речь она выдаёт латинскую бессмыслицу.

EchoRUS подменяет движок на Whisper: работает локально, без облака и API-ключей, аудио не покидает машину. Модель `large-v3-turbo` на CPU — 8 секунд на минуту речи.

Установка одной строкой в каталоге плагинов:
`https://shtazi98.github.io/echorus-voice/index.json`

**Вариант с деталями (для профиля или чата):**

Сделал плагин для DeepSeek Harness: голосовой ввод на русском через Whisper.

Что внутри:
— локальное распознавание, ничего не уходит в сеть
— сам ставит Python-зависимости и качает модель при первом запуске
— глоссарий терминов и словарь подстановок: «кубернетес» превращается в `Kubernetes`
— работает и для других языков, Whisper знает около сотни

Что выяснилось по ходу:
— `large-v3` на неразборчивой речи уверенно сочиняет, `large-v3-turbo` точнее и втрое быстрее
— транспорт Xet у Hugging Face молча висит на части сетей, лечится одной переменной
— кэш моделей на Windows без симлинков занимает вдвое больше места

Ставится так: Plugins → Discover → Add index → `https://shtazi98.github.io/echorus-voice/index.json`

MIT, модель качается отдельно.
