# EchoRUS

Локальный голосовой ввод для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) на Whisper.
Русский — в приоритете, но понимает любой из ~99 языков Whisper.

Штатный голосовой ввод DSH работает на SenseVoice и знает только китайский, английский, японский,
корейский и кантонский. EchoRUS добавляет в ту же кнопку микрофона распознаватель на Whisper:
работает офлайн, без API-ключей и подписок, аудио не покидает машину.

Как это делалось и что вылезло по дороге: [статья на русском](https://habr.com/ru/sandbox/316604/)
и [English write-up](https://shtazi98.github.io/echorus-voice/en.html).

## Что нужно

- Python 3.9+ в системе ([python.org](https://www.python.org/downloads/), на macOS и Linux обычно уже есть).
  Другой интерпретатор можно указать переменной окружения `ECHORUS_PYTHON`.
- ~2 ГБ на диске: пакеты распознавателя и модель.
- CPU достаточно. GPU не требуется.

## Установка

**Из GitHub (проще всего).** **Plugins → Add plugin** → вставьте:

```
github:Shtazi98/echorus-voice
```

Для этого способа на машине нужен `git`.

**Из локальной папки.** Скачайте репозиторий и укажите **Plugins → Add plugin → локальная директория**.

**Из npm.** После первой публикации пакет ставится по имени `dsh-echorus-voice`.

Первый запуск требует интернета: плагин сам скачает пакеты `faster-whisper` и модель.
Дальше всё работает офлайн.

## Использование

1. Откройте настройки голосового ввода (кнопка микрофона в поле ввода).
2. Дождитесь окончания установки — прогресс виден там же.
3. Выберите провайдер **EchoRUS (Whisper, local)** и язык.
4. Нажмите микрофон, говорите, отпустите. Текст вставится в поле ввода.

## Модели

| Модель | Размер | Скорость (CPU) | Когда выбирать |
|---|---|---|---|
| `small` | ~0,5 ГБ | быстро | слабое железо, короткие заметки |
| `medium` | ~1,5 ГБ | средне | компромисс |
| `large-v3-turbo` | ~1,6 ГБ | быстро и точно | по умолчанию |
| `large-v3` | ~3 ГБ | медленно | максимальная точность, мощный CPU |

Практика на русском: `large-v3-turbo` обычно точнее `large-v3` при вдвое меньшей задержке —
крупная модель на неразборчивых фрагментах уверенно сочиняет. Модель меняется в настройках плагина.

## Настройки

Все параметры задаются в строке плагина (`cordis.patch.yml`) или в патче профиля:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `dataRoot` | `dshHomePath('echorus-voice')` | каталог для пакетов, моделей и временных файлов |
| `model` | `large-v3-turbo` | размер модели: `small`, `medium`, `large-v3-turbo`, `large-v3` |
| `languages` | `ru`, `en`, `auto` | какие языковые подсказки принимает провайдер |
| `glossary` | пусто | ваши термины через запятую — попадают в подсказку и закрепляют написание |
| `replacements` | пусто | словарь подстановок `Кириллица=Latin`, применяется к готовому тексту |
| `prompt` | русская деловая диктовка | контекстная подсказка модели вместо стандартной |
| `keepAudio` | `false` | оставлять последнюю запись в `tmp` для отладки |
| `pythonPath` | автопоиск | конкретный интерпретатор Python |

Пример с глоссарием:

```yaml
- id: echorus-voice
  config:
    dataRoot: !!js dshHomePath('echorus-voice')
    model: large-v3-turbo
    glossary: иммобилайзер, Кубернетес, Постгрес, Nginx, Grafana
```

На проверке глоссарий подтянул имена собственные (`Kubernetes`, `PostgreSQL`), но сбивал пунктуацию.
Поэтому по умолчанию работает контекстная подсказка без глоссария — она дала и пунктуацию, и заглавные буквы.
Список терминов добавляйте, когда в диктовке появляются устойчивые названия.

Английские названия, которые в русской речи звучат по-русски, надёжнее не «учить» распознавать, а
подставлять словарём:

```yaml
    replacements: Кубернетес=Kubernetes, Постгрес=PostgreSQL, Нжинкс=Nginx
```

Замена идёт по целым словам и не зависит от регистра: «кубернетес» и «Кубернетес» станут `Kubernetes`.
Падежные формы («Кубернетеса») намеренно не трогаются, иначе получилась бы смесь алфавитов `Kubernetesа` —
для них добавляйте отдельную пару.

## Языки

По умолчанию `ru`, но провайдер принимает языковые подсказки Whisper (`en`, `de`, `fr`, `es`, `zh` и другие)
и умеет автоопределение (`auto`).

## Приватность

Аудио пишется браузером, передаётся на локальный хост, распознаётся локально и удаляется сразу после
расшифровки. Наружу уходят только запросы на скачивание пакетов и модели при первой установке.
Для отладки можно включить `keepAudio`, тогда последняя запись остаётся в `tmp` каталога данных.

## Ограничения

- Только CPU. GPU не используется.
- Модель загружается на каждый запрос: к расшифровке добавляется несколько секунд.
- Нет разделения по говорящим и ручной правки пунктуации — что дал Whisper, то и вернулось.
- Первая установка качает ~2 ГБ.

## Устройство

- `index.js` — провайдер `echorus-local` в реестре `speechToText`, поиск Python, установка пакетов, скачивание модели.
- `python/echorus_stt.py` — один вызов распознавания, JSON на выходе.
- `cordis.patch.yml` — регистрация строки плагина и выбор провайдера по умолчанию.

# EchoRUS (English)

Local Whisper-based voice input for DeepSeek Harness. Russian first, ~99 languages supported.
No cloud, no API keys, audio stays on the machine.

Requirements: Python 3.9+, ~2 GB disk, CPU is enough. Install the `dsh-echorus-voice` package or point
**Plugins → Add plugin** at this directory, then finish the one-time setup in the voice settings and pick
**EchoRUS (Whisper, local)**.

MIT licensed. Model weights are not bundled; they are downloaded on first use.
