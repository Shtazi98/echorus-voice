# EchoRUS

Локальный голосовой ввод на Whisper для DSH. Добавляет провайдера `echorus-local` в стандартную кнопку
микрофона, не меняя интерфейс.

## Что делает

- Ищет Python 3.9+ в системе и при первом запуске ставит `faster-whisper` в каталог данных плагина.
- Скачивает выбранную модель Whisper один раз и переиспользует её.
- Распознаёт русскую речь (и любой другой язык Whisper) полностью на машине пользователя.
- Вставляет текст в поле ввода; отправка сообщения остаётся за человеком.

## Что учитывать

- Требуется Python и около 2 ГБ диска; первая установка идёт с интернетом.
- CPU-only, модель загружается на каждый запрос — к расшифровке добавляется несколько секунд.
- Аудио удаляется сразу после распознавания; сохранять его можно только включив отладку.
