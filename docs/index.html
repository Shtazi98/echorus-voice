EchoRUS

Голосовой ввод на Whisper для DeepSeek Harness. Русский в приоритете.

Говорите вместо того, чтобы печатать. Кнопка микрофона в поле ввода записывает голос, распознаёт его локально и вставляет текст в чат. Аудио не покидает компьютер, ключи и подписки не нужны.

Штатный голосовой ввод DSH понимает китайский, английский, японский, корейский и кантонский. EchoRUS добавляет Whisper — русский и ещё около сотни языков.

Установка

  1. Откройте Plugins → Discover → Add index и вставьте адрес: 
    https://shtazi98.github.io/echorus-voice/index.json
  2. Найдите в каталоге EchoRUS voice input и нажмите Install.
  3. Первый запуск скачает распознаватель и модель (~2 ГБ). Прогресс виден в настройках голосового ввода.

Без каталога плагин ставится напрямую: Plugins → Add plugin и строка github:Shtazi98/echorus-voice. Для этого способа нужен установленный git.

Что требуется

Python 3.9+

Плагин найдёт его сам. Другой интерпретатор задаётся переменной ECHORUS_PYTHON.

~2 ГБ на диске

Пакеты распознавателя и модель. GPU не нужен, хватает процессора.

Интернет один раз

Только на первой установке. Дальше распознавание работает офлайн.

Настройка под себя

В строке плагина доступны model (от small до large-v3), glossary — список ваших терминов, и replacements — словарь подстановок, который пишет названия латиницей: Старлинк=Starlink.

Приватность

Запись передаётся только локальному процессу на вашей машине, распознаётся локально и сразу удаляется. Наружу уходят лишь запросы на скачивание пакетов и модели при первой установке.
